# Gapple TV

Transform sluggish, ad-ridden Android and Google TVs into a silky-smooth, privacy-first Apple tvOS interface.

- **Resident RAM**: Reduced from 320 MB to just 27.6 MB (>91% reduction)
- **Fluidity**: 60 FPS hardware-accelerated Leanback animations
- **No Ads**: Zero promotional banners or sponsored feeds
- **Frosted Glass**: Translucent sheets for Quick Settings and Wi-Fi drawers
